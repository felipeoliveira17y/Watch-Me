PRIVACIDADE E LIMITES

Uma plataforma de apoio

Esta versão é uma base local para gestão e demonstração. O dispositivo real ainda não está ligado, SMS não são enviados e a entrega de notificações não é confirmada.

Salas usam links secretos temporários. Quem possuir o link pode abri-lo; não é uma verificação de identidade. Salas reais não são expostas nesta versão inicial.

Os números 190 e 197 são referências brasileiras que devem ser confirmadas localmente. A aplicação não substitui os serviços oficiais de emergência.
